# aod-old

The aod.co.in website as it looked before the new design (21 Nov 2026), kept for reference. It has **no backend**: everything runs on sample data, what you type stays in your browser, and every field may be left empty (any email, password or code works). Not for search engines.

```bash
npm install
npm run dev     # http://localhost:3000 (admin: /admin, artist portal: /artists, Dispute Desk: /resolve)
npm run build
```

See `CLAUDE.md` for what was removed and how it works. The live site, with the backend, is the `aod` folder next to this one.
